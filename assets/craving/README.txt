Put your product photos here using these exact filenames:

  product-1.png     -> top-left floating pouch
  product-2.png     -> top-right floating pouch
  product-3.png     -> bottom-right floating pouch
  product-main.png  -> the big centered "PROTEIN BAR" panel

Square or landscape photos work well here since these fill small pill
shapes, except product-main.png which fills a larger square-ish panel.

Until a file is added, the illustrated placeholder for that spot stays
in place automatically.
